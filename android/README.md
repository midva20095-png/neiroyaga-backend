# НейроЯга для Android

Приложение открывает сайт [babayagaland.ru](https://babayagaland.ru/): чат, кабинет, ленту, оплату и ссылку на бота. Отдельного магазина внутри приложения нет — работает тот же сайт, вход и баланс сохраняются на телефоне.

Нужен Android 8 или новее. Готовый файл для установки: `NeyroYaga.apk`.

## Установка

1. Скачайте `NeyroYaga.apk` на телефон.
2. Откройте файл. Если система спросит разрешение, разрешите установку из этого источника.
3. Нажмите «Установить», затем «Открыть».
4. На рабочем столе появится «НейроЯга».

Обновление с тем же ключом подписи ставится поверх. Если подпись другая, сначала удалите старую НейроЯгу, затем установите новую.

## Что умеет

- Сайт на весь экран, без адресной строки браузера.
- Кнопка «Назад» возвращает на предыдущую страницу сайта.
- Вход, чаты и баланс остаются после закрытия приложения.
- К чату можно прикрепить фото, файл или снимок с камеры.
- Картинки и другие файлы сохраняются в «Загрузки».
- Оплата ЮKassa открывается внутри приложения и возвращает на сайт.
- Telegram, почта и телефон открываются своими программами.
- Если сайт не открылся, на экране есть «Повторить» и «Открыть в браузере».

На Samsung приложение выглядит для сайта как обычный браузер, без служебной метки WebView: иначе защита DDoS-Guard обрывает адрес и планшет пишет, что сайт не открылся. Если останется надпись «Адрес сайта не найден», в настройках планшета у «Личного DNS» выберите «Автоматически».

Приложение не добавляет свою рекламу и не собирает данные отдельно от сайта.
